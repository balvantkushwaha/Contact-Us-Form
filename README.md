# Contact Us Form

A simple and responsive Contact Us Form built using **HTML and CSS**. This project provides a clean interface for users to enter their contact details and submit an inquiry.

## 🚀 Live Demo

[View Live Website](https://mycontactformbvk.netlify.app/)

## 📸 Project Overview

The Contact Us Form is designed with a user-friendly layout to collect basic information from visitors.

## ✨ Features

- Clean and simple user interface
- Responsive design
- Name and email input fields
- Gender selection
- Subject and message fields
- Submit and Reset buttons
- Form autocomplete disabled

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📂 Project Structure

## ⚙️ Installation & Setup

1. Clone the repository:

```bash
git clone https://github.com/balvantkushwaha/Contact-Us-Form.git
```

2. Open the project folder:

```bash
cd Contact-Us-Form
```

3. Open `index.html` in your browser.
